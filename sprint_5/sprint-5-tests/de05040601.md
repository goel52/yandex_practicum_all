### Задание 1. Пропишите параметры подключения в Airflow

Airflow не поддерживает тип подключения MongoDB. Поэтому воспользуйтесь другим способом передачи параметров конфигурации — переменными.

Перейдите в разделы `Admin` -> `Variables`. Через кнопку `+` добавьте следующие параметры:

- MONGO_DB_CERTIFICATE_PATH="/opt/airflow/certificates/PracticumSp5MongoDb.crt"
- MONGO_DB_USER="student"
- MONGO_DB_PASSWORD="student1"
- MONGO_DB_HOST="rc1a-ba83ae33hvt4pokq.mdb.yandexcloud.net:27018"
- MONGO_DB_REPLICA_SET="rs01"
- MONGO_DB_DATABASE_NAME="db-mongo"

**ТУП**

Вы завели параметры подключения. Теперь в любых DAG и задачах внутри DAG можно подключаться к MongoDB, используя эти переменные. Заметьте, Airflow сам замаскировал значение переменной MONGO_DB_PASSWORD.

В коде DAG вы сможете получить значение переменной таким образом:

```python
# импортировать Variable
from airflow.models.variable import Variable

#------------------------------------
# затем в коде дага получить значения
cert_path = Variable.get("MONGO_DB_CERTIFICATE_PATH")
db_user = Variable.get("MONGO_DB_USER")
db_pw = Variable.get("MONGO_DB_PASSWORD")
rs = Variable.get("MONGO_DB_REPLICA_SET")
db = Variable.get("MONGO_DB_DATABASE_NAME")
host = Variable.get("MONGO_DB_HOST")
```
