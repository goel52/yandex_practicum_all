### Задание

- Был сначала квиз
    
    Вам необходимо написать DDL-скрипт для организации паттерна transactional outbox. Вам необходимо отправлять данные объекта пользователь.
    
    Объект пользователь содержит 2 поля:
    
    - user_id: int
    - user_name: string
    
    Выберите корректные DDL-скрипты для создания таблицы `outbox`.
    
    - [ ]  [ ]
        
        ```
            CREATE TABLE IF NOT EXISTS outbox (
                id int NOT NULL PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
                payload text NOT NULL
            );
        ```
        
        Не хватает указания типа объекта в поле `payload`. Без него будет сложно корректно десериализовать JSON.
        
    - [ ]  [ ]
        
        ```
            CREATE TABLE IF NOT EXISTS outbox (
                id int NOT NULL PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
                type varchar NOT NULL,
                payload text NOT NULL
            );
        ```
        
        Реализация содержит все необходимые поля. Для записи в payload объект User сериализуем в JSON.
        
    - [ ]  [ ]
        
        ```
            CREATE TABLE IF NOT EXISTS outbox (
                id int NOT NULL PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
                object_id int NOT NULL,
                record_ts timestamp NOT NULL,
                type varchar NOT NULL,
                payload text NOT NULL
            );
        ```
        
        Реализация содержит все необходимые поля, а также дополнительные. Соответственно, подходит в качестве таблицы для реализации transactional outbox.
        
    - [ ]  [ ]
        
        ```
            CREATE TABLE IF NOT EXISTS outbox (
                id int NOT NULL PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
                user_id int NOT NULL,
                user_name varchar NOT NULL,
                record_ts timestamp NOT NULL
            );
        ```
        
        Реализация могла бы подойти для отправки объектов типа User. Однако паттерн transactional outbox подразумевает отправку сообщений разных типов. Специфичные поля, характерные для объекта User - user_id и user_name -, затруднят распространение паттерна на объекты других типов.
        

Попробуйте самостоятельно написать DDL-скрипт для организации паттерна Transactional Outbox. Создайте таблицу `outbox` в схеме `public`. Вам необходимо отправлять данные произвольного объекта. Таблица должна содержать следующие поля:

- id: int
- object_id: int
- record_ts: timestamp
- type: varchar
- payload: text
- Авторское решение
    
    ```sql
    CREATE TABLE IF NOT EXISTS outbox (
            id int NOT NULL PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
            object_id int NOT NULL,
            record_ts timestamp NOT NULL,
            type varchar NOT NULL,
            payload text NOT NULL
        );
    ```
    
- ТУП
    
    Вы завели таблицу outbox. Далее из подобной таблицы позднее вы будете забирать данные.
    
- Подсказка
    
    DDL - Data Definition Language, т.е. вам необходимо написать CREATE TABLE команду. Не забудьте про ключи и ограничения.
