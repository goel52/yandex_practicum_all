Напишите запрос, который вернёт строки с информацией об атрибутах колонок всех таблиц из схемы `public`. Список таблиц из схемы `public` нужно получить в рамках этого же запроса. В результате вы должны получить следующую информацию:

- название таблицы;
- название колонки;
- тип данных в колонке;
- для строковых типов — максимальная длина значения в колонке;
- значение по умолчанию для колонки;
- может ли в колонке быть значение `NULL`.

Строки в результате запроса должны быть отсортированы в алфавитном порядке по названию таблицы.

- Авторское решение
    
    ```sql
    select table_name, column_name, data_type, character_maximum_length, column_default, is_nullable  
     from information_schema.columns  
      where table_schema = 'public' and  
       table_name in (select table_name from information_schema.tables where table_schema = 'public') 
        order by table_name;
    ```

- **Какая система выступает в качестве источника.**
    
    Вместо БД источником может стать некий сервис, который передаёт данные по API. Чтобы изучить данные такого источника, нужно лишь исследовать документацию по API или получить информацию от владельца сервиса. 
    
- **Какие данные лежат в таблицах.**
    
    Данные могут быть в составном формате в одной колонке, и их нужно разделить, прежде чем достать.
