# Проверка текстового вывода Spark

Для de07040402, de07040604, de07040801 и de07040902 проверяется структура
вывода, а не наличие отдельных слов. Ответ студента не исполняется, JVM не нужна.

- **de07040402**: две колонки `event`, `event_type`, 10 строк, дата 2022-05-25
  в событии и тип `subscription`, как в первых строках предоставленного учебного
  набора. Порядок строк и конкретные часы событий не фиксируются.
- **de07040604**: все 15 строк объединения; `title`, `author`, `book_id`
  сопоставляются в пределах одной строки. Порядок строк свободный, дубликат
  вместо отсутствующей книги не принимается.
- **de07040801**: первые 10 строк отсортированного учебного набора; проверяются
  `event_type`, `hour`, `minute`, `second` в порядке убывания времени события.
  Само поле `event` обрезается `show()` и целиком не сравнивается.
- **de07040902**: полный набор путей полей, их типы и nullable/containsNull.
  Порядок соседних полей не важен, вложенность важна.

Общий разбор расположен в `text_output.py`. Пробелы по краям ячеек,
CRLF, ширина рамки таблицы и порядок колонок не влияют на результат.
Для длинных значений UNION принимаются эталонное сокращение `show()` и полный
текст с тем же видимым префиксом. Невидимая часть сокращённого значения
не позволяет проверить всю строку; это ограничение текстового контракта.

Эталоны в `src/sprint_7_check_service/lessons/pyspark_for_data_engineer/expected_outputs/`
взяты из авторских ответов соответствующих заданий. Они поставляются с сервисом
внутри `src`, независимо от каталога тестов. При изменении учебного набора данных
нужно пересмотреть и эталоны, и авторские ответы. В частности, проверка
`subscription` в de07040402 относится к текущему учебному набору, а не является
универсальным свойством JSON или гарантией порядка строк Spark.

Регрессии: `tests/unit/test_text_output_checks.py`. Они покрывают четыре ложных
успеха из прогона пути студента, ошибки структуры и значений, допустимое
форматирование и ответы API без выдачи кода платформы при ошибке.
