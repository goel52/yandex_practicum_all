### Задание 6. Заполните таблицу `dm_orders`

Таблица заказов `dds.dm_orders` ссылается сразу на три удалённых измерения: «Рестораны», «Пользователи», «Временные метки». Загрузка должна учитывать эти ссылки. 

Добавьте в DAG новый шаг для заполнения таблицы `dds.dm_orders`, который: 

1. Прочитает данные о заказе.
2. Найдёт нужные версии объектов с учётом `id` связанных объектов и отметки времени заказа.
3. Вставит запись в заказ.

**Подсказка**

В STG данные о заказе лежат в формате JSON. Поэтому логика шага может выглядеть таким образом:

1. Прочитать данные из таблицы в STG.
2. Преобразовать JSON к объекту.
3. Найти версию ресторана по `id` и `update_ts`.
4. Найти версию пользователя по `id` и `update_ts`.
5. Найти временную метку по `date` в заказе.
6. Вставить объект заказа в таблицу.

**ТУП**

Логика заполнения всех измерений собрана. Пора переходить к центральной таблице — таблице фактов.
