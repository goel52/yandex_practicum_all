 Примечания
 
 - данные берем за два дня, в API запросе фильтрация по дате заказа. Если заказ был заказан вечером, доставка может быть на следующий день и не попасть в выгрузку. Пока не видел, чтобы студенты обращали на это внимание, но, может быть, заметят 
 
 - витрина собирается ежедневно с перезаписыванием данных за текущий месяц, согласно заданию
